# 历史回放严格时间切片与策略准确率边界

## 规则：绝不使用选股日之后的信息

截至2026-10-26，本工具完成2026-09-21至2026-10-22共18个历史交易日的逐日价格/成交额子规则回放。研究日d的选股阶段只读日期不晚于d的历史记录；后续行情只能在全部候选生成和冻结后进入第二阶段计算D+1、D+3等表现。

## 已落地的防作弊约束

- 历史时间切片读取函数禁止访问选股日期之后的行情；越界直接报错。
- 先执行选择，再进行结果评价；未来价格不会传回选择器。
- 测试会故意改动未来一天的价格，要求当时的候选名单与SHA-256校验指纹完全相同。
- 冻结名单已由独立GitHub Actions提交，固定在 replay/asof/frozen-selections.json；SHA-256为bd606c62f621ab4401bcc4ab76ed4984abfaaf0c201c95890a13c1860f9a12e0。
- 网站后续部署只读取已经冻结的候选，允许增加后续走势，不再替换过去的观察名单；修改冻结文件会触发完整性检查失败。
- 这批记录统一标为 TECHNICAL_PRESCREEN_ONLY，不混入真正发生过的18:00定时推荐胜率。
- 历史预筛期不足6个交易日时只报告预热，不生成虚构股票。

## 必须明确：这不是原策略的完整历史重放

- 当前仓库只有约19个交易日的个股收盘价和成交额，未拥有完整20/60日价量、最高最低、复权除息、换手与盘中成交证据。
- 过去每一天的行业主力资金、催化事件、公告及财报，缺少可以证明当时就已公开的完整时间戳资料。
- 原来的L1-L4框架是自然语言研究规则，不是此前已经冻结的精确算法。2026-10-26才编写的量价预筛阈值，也可能受到研究者事后观察历史行情的影响；**程序层面无未来价格读取，并不等于没有研究者后见之明**。
- 历史股池可能沿用后来的上市名单，存在幸存者偏差。
- 收盘到次日收盘的方向统计，不等于交易信号触发、可成交成本、T+1后卖出或含手续费的实盘收益。

## 下一阶段真正检验原策略，需要的证据

1. 对每个研究日期补齐其之前至少60个交易日的历史OHLCV，交易状态和复权/分红信息。
2. 每条申万行业资金、公告、政策、财报、订单数据保存来源和当时可用时间（available_at），只允许available_at不晚于研究截止时刻的证据入选。
3. 将原L1-L4、A/B/C分池和买卖条件版本化并冻结，再逐日从全股票池运行，保留失败案例，禁止调参后覆盖旧版本。
4. 区分真实曾经推送的原文、事后重建研究及研究规则预筛；不得混在一个策略胜率指标中。
5. 以信号生成后的下一个可交易时刻作为交易起点，使用合理OHLCV、涨跌停和流动性限制、T+1、滑点及费用核算可执行收益与最大回撤；条件未触发记为未交易。
6. 把尚未见过的未来日期留为样本外区间，用冻结规则检验是否稳定跑赢市场。

只有完成这些步骤，才能对完整策略的准确性与长期盈利能力给出可靠结论。
