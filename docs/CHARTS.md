# A股雷达 · 图表可视化规范

这个项目的核心是 **ChatGPT 18:00日报历史归档和阅读**，不是自动交易或数据统计产品。图表只为读者理解历史报告服务，**不会改写日报、偷换股票结论或重新计算原先不知道的行情**。

## 目前显示什么

1. **本期报告观察股票**：严格从报告 Markdown 中具有股票名称、六位代码的表格提取数据，并保留A/B/C池别（如原表写明）；未写池别归为“未标”，不会显示成A/B/C的0。是原文表格出现数量，不是实际持仓、上涨概率或收益率。
2. **行情快照涨跌家数**：仅从已归档、日期校验通过的股票行情统计“上涨、下跌、平盘、涨跌幅缺失”。按当前采集股票数量算比例；不自动等价交易所全市场。
3. **成交额 Top10**：按同一日的实际股票成交额排名。行情样本可能包含科创板等股票，与投资候选筛选池（仅主板、创业板）范围不同。
4. **单日/多日市场成交额**：当日期只有一天时显示一根柱及其单位，不虚构走势；多日必须是相同统计范围才能比较，不将成交额当净流入。
5. **两日行业成交额 + 估算主力净流向**：只有行业分类同源且同一级分类、资金净额和行业成交额均可核验时才绘制；红=净流入，绿=净流出，以零为中轴，不暗示资金从一个板块转账到另一板块。

## 防止事后信息泄漏

在历史日报阅读中有三个选项：

- **本期报告**：只用当前归档文章的股票表格，内容不变；
- **对应日期行情**：仅显示当期报告日期或更早日期可用的数据快照，不自动选择“未来”的行情；
- **最新行情（独立查看）**：用户主动选择后可看最新数据，若晚于当前报告，会有显著警告，不能将其作为原始报告的证据。

单独查看的行情数据不属于原日报的一部分，也不能用于编辑或替换历史观点。

## 真实数据链路

\`data/snapshots/YYYY-MM-DD.json\` （实时已核验归档，不是测试样本）
↓
\`scripts/build_chart_data.py\` （日期、股票数、汇总数一致性检查）
↓
\`data/market-history.json\` （轻量图表数据）
↓
\`assets/charts.js\` + \`assets/charts.css\` （GitHub Pages展示）

- \`pages.yml\` 每次部署运行 Python 数据生成脚本及离线校验。
- \`collect.yml\` 采集成功后发布 Pages 时，同样运行数据生成脚本。
- 数据文件不含模拟行情，所有样本测试仅存在 \`tests/test_chart_data.py\` 的临时目录。
- 如果 AKShare/腾讯行情采集失败，最新图表不会使用编造数据补齐。
- 当前只有2026-10-20一日快照，行业主力数据尚不完整，双日行业资金图因此应当显示缺失说明。
- 代码提交和静态检查成功不代表线上 Pages 已经部署并经过浏览器交互测试。
