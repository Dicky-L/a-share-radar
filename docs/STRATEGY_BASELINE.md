# A股启动与卖出雷达｜策略基线与网站发布职责

最后确认：2026-10-26。**本次网站产品形态调整不改变任何原有筛选或交易研究规则。** 这份文档仅记录策略契约，不是已完成的历史回测报告。

## 选股策略保持不变

- **覆盖范围**：沪市主板、深市主板及创业板300/301；默认排除688科创板、北交所、ST/*ST、停牌和明显低流动性证券。
- **L1–L4漏斗**：先看市场/板块方向与5/20/60日量价、换手、波动和相对指数；再核验资金筹码与板块扩散；结合7/30/90日催化、订单/业绩/政策；最终用财报、治理、拥挤和流动性排雷。选股目标是潜在3—10个交易日的早期启动信号，**不是追逐已涨停的后验热门**。
- **A池**：价量、行业板块、资金、催化四类证据中至少三类可核实且风险排查通过；仍须符合实际入场触发，不能等同立即买入。
- **B池**：有值得观察的逻辑但突破、成交量、板块资金等尚未确认；仅等待条件，**不视为已经买入**。
- **C池**：拥挤过热、结构失效或风险恶化；不再按旧信号新开仓。原来是否持有须另行以真实交易信息管理，不能把C池等同自动卖出。
- **每只股票当期必须回答**：代码/公司与行业、观察理由、价量确认与不得追高条件、失效条件、分批止盈和卖出管理、风险与观察窗口。证据不充分可不给A池；最多10只，不凑数。
- **风险限制**：3%—5%止损、5%—8%分批止盈、约3%盈利回撤保护、5交易日时间退出等仅属尚未完成严格回测的纪律示例；以股票波动、实际成交价、费用和普通A股T+1限制校准，不保证收益。
- **回测/绩效**：每一批原始候选和失败案例都应保留；后续价量验证不允许倒填改变原始判断。观测收盘涨幅与策略成交后的净利润严格区分；重复的同代码候选也不能视作独立投资案例。
- **行情真实性**：AKShare主数据源先验证，预留Tushare/富途适配；缺失数据保留缺失状态；真实盘后收盘与数据源估算主力资金要分清；不要以模拟行情冒充真实市场数据。

## 本次仅变更发布体验，不更换策略

**之前**：18:00在ChatGPT输出完整报告，网站更多用于归档行情和过去的候选。

**现在**：18:00依然按相同策略输出完整报告；同一份公开脱敏版本尝试写入 `reports/YYYY-MM-DD.md`，由Pages编译为网页版；首页优先显示当天已经核验的完整报告。**之前所有已归档当期推荐**在首页`之前推荐的股票 · 持续跟踪`中持续显示原始日期、最初逻辑/买卖条件和最新可核实收盘观察表现；其历史池别不因今天首页显示而自动升级为今天的新候选。

- 网站持续跟踪使用 `reports/candidates.json` 与 `reports/performance.json` 两份部署时生成的索引。
- 成果可见与否取决于当期完整日报是否**真正写入GitHub并成功部署**；更新股票行情快照不会自动生成投资研究正文。
- 截至2026-10-26下午，仓库最新的日报正文是2026-10-21；10月23—25日网站全文发布核验失败。不得声称这些日期的网站完整日报已同步。
- 日报可能包含敏感真实持仓；公开网站不应存储持仓成本、数量、账户及其他私人财务信息，除非已安全脱敏。不能脱敏则保持在私有聊天，不得假装网站已同步。
- 网站自动发布没有完成多日成功验收之前，ChatGPT仍保留完整每日推送作为容灾；成功后才能将聊天逐步改为短通知或链接。
